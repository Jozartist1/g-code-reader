        Blueprint

        Learn to read G-code by running it

        What this is

        The G-code Reader — a way to learn Haas mill programs by running one. Your full LME 01 program from MACH 130 is loaded: the face, the profile, the drilling, and the slot. The map draws the cut line by line, and you name the code that makes each move.

        Why it was made

        A code list can tell you what a code means. It can’t show you what the tool does when that code runs. This was made to close that gap, so the meaning of a code is something you watch happen, not something you memorise.

        What you’re about to do

        Run the whole program the way the machine does, one line at a time — 276 codes across 108 lines. For each one, the cut is drawn before you answer, and the meaning is revealed only after. Anything you miss comes back at the end for a retry round.
